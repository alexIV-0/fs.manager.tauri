# ui.json — Описание UI-ноды плагина

Файл `ui.json` описывает визуальную ноду, которая появляется на холсте ReactFlow. Система читает этот файл и строит интерфейс ноды автоматически на основе его содержимого. Путь до файла указывается в поле `ui` манифеста `plugin.json`.

---

## Полная структура

```json
{
	"id": "myPlugin",
	"type": "myPlugin",
	"position": { "x": 0, "y": 0 },
	"width": 350,
	"height": 480,
	"deletable": true,
	"data": {
		"label": "My Plugin",
		"comment": "Краткое описание что делает нода",
		"colorType": "main",
		"isUnique": false,
		"required": false,
		"isValid": false,
		"executionType": "default",
		"properties": [],
		"output": {
			"sourceProperty": "inputFile"
		}
	}
}
```

---

## Корневые поля

### `id`

**Тип:** `string`  
**Обязательное:** нет (проставляется автоматически)

Идентификатор ноды в ReactFlow. При добавлении ноды на холст система генерирует уникальный id. В файле `ui.json` можно не указывать или указать как заглушку.

---

### `type`

**Тип:** `string`  
**Обязательное:** да

Тип ноды. Должен совпадать с `id` плагина. По этому значению система находит нужный React-компонент для рендеринга ноды.

```json
"type": "mainSearch"
"type": "copyItem"
"type": "splitFile"
```

---

### `position`

**Тип:** `{ x: number, y: number }`  
**Обязательное:** нет

Начальная позиция ноды на холсте при первом добавлении. Обычно `{ "x": 0, "y": 0 }` — система сама разместит ноду в нужном месте.

---

### `width`

**Тип:** `number`  
**Обязательное:** да

Ширина ноды в пикселях. Подбирается вручную под контент.

```json
"width": 350
```

---

### `height`

**Тип:** `number`  
**Обязательное:** да

Высота ноды в пикселях. Должна соответствовать реальному содержимому, иначе контент будет обрезан или будет лишний отступ.

```json
"height": 480
```

---

### `deletable`

**Тип:** `boolean`  
**Обязательное:** нет (по умолчанию `true`)

Можно ли удалить ноду с холста. Если `false` — нода обязательная и её нельзя удалить (например, нода `Search IN` или `Description`).

```json
"deletable": false
```

---

## Поля внутри `data`

### `label`

**Тип:** `string`  
**Обязательное:** да

Отображаемое название ноды в заголовке.

```json
"label": "Copy File"
```

---

### `comment`

**Тип:** `string`  
**Обязательное:** нет

Подсказка/описание под заголовком ноды. Виден пользователю прямо на карточке.

```json
"comment": "Копируем элемент в нужную папку"
```

---

### `colorType`

**Тип:** `string`  
**Обязательное:** да

Определяет цветовую тему ноды (цвет заголовка, хэндлеров и акцентных элементов). Значение должно совпадать с одним из зарегистрированных типов цветов в настройках `Options → Nodes`.

**Встроенные значения:**

| Значение    | Описание                                       |
| ----------- | ---------------------------------------------- |
| `"main"`    | Синий — основные ноды поиска и сохранения      |
| `"helpers"` | Зелёный/нейтральный — вспомогательные ноды     |
| `"ffmpeg"`  | Специальный цвет для нод работы с медиафайлами |

Пользователь может добавлять собственные цветовые типы в настройках приложения (`Options → Nodes`). Туда же попадают цвета из плагинов, если у плагина есть уникальный `colorType`.

```json
"colorType": "main"
"colorType": "helpers"
"colorType": "ffmpeg"
```

---

### `isUnique`

**Тип:** `boolean`  
**Обязательное:** нет (по умолчанию `false`)

Если `true` — на холсте может существовать только один экземпляр этой ноды. При попытке добавить вторую система заблокирует действие.

```json
"isUnique": true
```

> Используется для ключевых нод, которые должны быть единственными: `Search IN`, `Description`.

---

### `required`

**Тип:** `boolean`  
**Обязательное:** нет (по умолчанию `false`)

Если `true` — нода считается обязательной для валидного flow. Без неё весь flow не пройдёт валидацию.

```json
"required": true
```

---

### `isValid`

**Тип:** `boolean`  
**Обязательное:** да (всегда инициализируется как `false`)

Текущее состояние валидности ноды. В `ui.json` всегда должно быть `false` — система сама выставляет это значение в рантайме на основе заполненности обязательных полей и корректности соединений.

```json
"isValid": false
```

---

### `executionType`

**Тип:** `string`  
**Обязательное:** нет

Определяет особый режим выполнения ноды при обработке. Если не указан — обычное последовательное выполнение.

| Значение | Описание                                                                               |
| -------- | -------------------------------------------------------------------------------------- |
| `"loop"` | Нода является итератором — повторяет выполнение для каждого элемента входящего массива |

```json
"executionType": "loop"
```

---

### `output`

**Тип:** `object`  
**Обязательное:** нет (обязательно если нода что-то передаёт дальше)

Описывает, что нода передаёт следующей ноде и какую функцию вызывает при обработке.

```json
"output": {
  "sourceProperty": "inputFile"
}
```

| Поле | Тип | Описание |

| `sourceProperty` | `string` | `id` свойства из `properties`, значение которого будет передано как выходные данные следующей ноде. Если пустая строка — нода ничего не передаёт |

---

## Массив `properties`

Каждый элемент массива — это одно поле ввода (контрол) внутри ноды.

### Общая структура свойства

```json
{
  "id": "inputFile",
  "controlType": "link",
  "controlProps": { ... },
  "isInput": true,
  "isOutput": false,
  "acceptedTypes": ["video", "audio"],
  "outputType": "accepted",
  "required": true
}
```

---

### `id`

**Тип:** `string`  
**Обязательное:** да

Уникальный идентификатор поля внутри ноды. Используется как ключ при сборке итогового объекта для обработки и при ссылке из `output.sourceProperty`.

```json
"id": "inputFile"
"id": "targetPath"
"id": "deleteAfter"
```

---

### `controlType`

**Тип:** `string`  
**Обязательное:** да

Тип UI-компонента, который будет отрендерен для этого свойства.

| Значение         | Описание                                                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `"text"`         | Текстовое поле только для отображения. Обычно используется как точка подключения входящего хэндлера (принимает данные от предыдущей ноды) |
| `"autocomplete"` | Поле с автодополнением и чипами. Может быть мультиселектом, поддерживает ввод свободного текста или только выбор из списка                |
| `"checkbox"`     | Переключатель true/false                                                                                                                  |
| `"slider"`       | Ползунок с числовым значением                                                                                                             |
| `"timecode"`     | Специальный ввод таймкода в формате `HH:MM:SS`                                                                                            |
| `"loop"`         | Специальный контрол для ноды-итератора. Принимает массив и отображает элементы для итерации                                               |
| `"encodeSettings"` | Настройки кодирования выхода (контейнер/кодек/preset/CRF/pix_fmt/alpha). **В теле ноды не рисуется** — правится шестерёнкой в шапке ноды |

---

### `controlProps`

Свойства конкретного контрола. Зависят от `controlType`.

---

#### Для `"encodeSettings"`

Невидимое свойство: нужно ffmpeg-нодам, которые перекодируют видео, но своего окна
настроек не имеют (например `splitFile`). В теле ноды оно ничего не рисует — попап
открывается шестерёнкой в шапке ноды.

| Ключ      | Тип      | Описание                                                                                             |
| --------- | -------- | ---------------------------------------------------------------------------------------------------- |
| `label`   | `string` | Подпись (видна только в подсказке попапа)                                                            |
| `tooltip` | `string` | Текст всплывающей подсказки                                                                          |
| `profile` | `string` | Набор дефолтов: `standard` \| `quality` \| `fastCut` \| `hapMov` (см. `ENCODE_PROFILES` в `src/Utils/ffmpegCaps.ts`) |
| `value`   | `string` | JSON настроек. Пустая строка = «дефолт профиля», и это нормальное начальное состояние                 |

Профиль обязан совпадать с фолбэком в коде плагина, иначе попап покажет одно, а рендер
сделает другое:

```ts
import { buildEncodeArgs, encodeExt, parseEncodeSettings } from '../../src/Utils/ffmpegCaps';

const enc = parseEncodeSettings(_item.encode, 'fastCut');   // тот же профиль, что в ui.json
const outFile = `${name}.${encodeExt(enc, fileFrom)}`;      // расширение = контейнер
await ffmpeg.run({ command: ['-y', '-i', fileFrom, ...buildEncodeArgs(enc), outFile], … });
```

У ноды со СВОИМ окном настроек (`keying`, `overlaySettings`, `titleSettings`,
`videoAdjustment`) это свойство не нужно: попап пишет `encode` внутрь JSON того же
свойства, а плагин читает `settings.encode`.

```json
"controlProps": {
  "label": "Input File",
  "tooltip": "Подсказка при наведении",
  "value": ""

```

| Поле      | Тип      | Описание                                                                          |
| --------- | -------- | --------------------------------------------------------------------------------- |
| `label`   | `string` | Подпись поля                                                                      |
| `tooltip` | `string` | Текст всплывающей подсказки                                                       |

#### Для `"autocomplete"`

```json
"controlProps": {
  "label": "Target Path",
  "tooltip": "Куда сохранить файл",
  "options": ["#pathPattern", "#folders", "Custom Folder..."],
  "multiSelect": true,
  "optionsOnly": false,
  "allowDuplicates": true,
  "value": []
}
```

| Поле              | Тип        | Описание                                                                               |
| ----------------- | ---------- | -------------------------------------------------------------------------------------- |
| `label`           | `string`   | Подпись поля                                                                           |
| `tooltip`         | `string`   | Текст всплывающей подсказки                                                            |
| `options`         | `string[]` | Список вариантов для выбора. Поддерживает специальные теги (см. ниже)                  |
| `multiSelect`     | `boolean`  | Разрешить выбор нескольких значений (чипы). По умолчанию `false`                       |
| `optionsOnly`     | `boolean`  | Если `true` — запрещён свободный ввод, только выбор из `options`. По умолчанию `false` |
| `allowDuplicates` | `boolean`  | Разрешить добавление одного значения несколько раз. По умолчанию `false`               |
| `value`           | `string[]` | Начальные выбранные значения                                                           |

---

##### Специальные теги в `options`

В массиве `options` у `autocomplete`-контрола можно использовать специальные теги, начинающиеся с `#`. При раскрытии выпадающего списка система динамически подставляет реальные значения вместо тегов.

| Тег              | Что подставляется                                                                                                          |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `"#typeOfFile"`  | Список всех зарегистрированных типов файлов из `Options → Types` (video, audio, image, text, aep, moho и пользовательские) |
| `"#pathPattern"` | Список всех доступных паттернов для имён файлов/папок (переменные `$clearName`, `$findTime`, `$id` и т.д.)                 |
| `"#filePattern"` | То же, что `#pathPattern` — полный список переменных для формирования пути/имени файла                                     |
| `"#folders"`     | Список дочерних папок из текущей рабочей папки проекта (исключая служебные: `in`, `options`, `out`)                        |

**Пример использования:**

```json
"options": ["#pathPattern", "Custom Folder..."]
```

→ При открытии списка пользователь увидит все доступные `$`-переменные плюс пункт "Custom Folder..." для ввода своего пути.

```json
"options": ["#typeOfFile", "folders"]
```

→ Пользователь увидит все зарегистрированные типы файлов и отдельный вариант "folders" для поиска папок.

```json
"options": ["#folders"]
```

→ Пользователь увидит реальные папки из текущего рабочего каталога.

### `isInput`

**Тип:** `boolean`  
**Обязательное:** нет (по умолчанию `false`)

Если `true` — на левой стороне ноды у этого поля появляется входящий хэндлер (точка подключения). Через него данные передаются от предыдущей ноды.

```json
"isInput": true
```

---

### `isOutput`

**Тип:** `boolean`  
**Обязательное:** нет (по умолчанию `false`)

Если `true` — у поля есть выходящий хэндлер (правая сторона ноды). Данные из этого поля могут передаваться следующей ноде.

```json
"isOutput": true
```

> Можно комбинировать `isInput: true` и `isOutput: true` на одном поле — тогда у поля есть оба хэндлера. Это означает, что данные проходят насквозь через ноду (например, в `splitFile` поле `inputFile` является и входом и выходом).

---

### `acceptedTypes`

**Тип:** `string[]`  
**Обязательное:** нет

Список типов данных, которые это поле принимает или выдаёт через хэндлер. Используется для валидации соединений между нодами — нельзя соединить выход одного типа со входом несовместимого типа.

**Типы файлов:**

| Значение            | Описание                          |
| ------------------- | --------------------------------- |
| `"video"`           | Видеофайлы (mp4, mov, avi, ...)   |
| `"audio"`           | Аудиофайлы (mp3, wav, ...)        |
| `"image"` / `"img"` | Изображения (jpg, png, tiff, ...) |
| `"text"`            | Текстовые файлы (txt, json, ...)  |
| `"aep"`             | Файлы After Effects               |
| `"moho"`            | Файлы Moho                        |
| `"files"`           | Любые файлы                       |
| `"folders"`         | Папки                             |
| `"all"`             | Любой тип (файлы и папки)         |

**Специальные типы:**

| Значение     | Описание                                                               |
| ------------ | ---------------------------------------------------------------------- |
| `"path"`     | Строка с путём или паттерном пути (не файл, а строковые данные)        |
| `"timecode"` | Числовое значение таймкода в секундах                                  |
| `"accepted"` | Специальное значение: принимает любой тип, указанный в `acceptedTypes` |

```json
"acceptedTypes": ["video", "audio"]
"acceptedTypes": ["path"]
"acceptedTypes": ["video", "audio", "image", "text", "aep", "moho", "folders", "all"]
```

---

### `valueType`

**Тип:** `string`  
**Обязательное:** да

Определяет, как интерпретируется значение поля при сборке итогового объекта для обработки.

| Значение            | Описание                                                                         |
| ------------------- | -------------------------------------------------------------------------------- |
| `"accepted"`        | Значение — это файл/папка, тип определяется по `acceptedTypes` и входящим данным |
| `"array"`           | Значение — это массив строк (например, выбранные типы файлов)                    |
| `"path"`            | Значение — строка или массив строк, представляющих путь/паттерн                  |
| `"boolean"`         | Значение — булево `true` / `false`                                               |
| `"string"`          | Значение — строка                                                                |
| `"timecode"`        | Значение — число в секундах                                                      |
| `"typeByExtension"` | Тип определяется по расширению файла (например, для конвертации в нужный формат) |
| `"number"`          | Числовое значение (используется для слайдеров)                                   |

---

### `required`

**Тип:** `boolean`  
**Обязательное:** нет (по умолчанию `false`)

Если `true` — поле обязательно для заполнения. Нода не будет считаться валидной, пока это поле не заполнено или не подключено через хэндлер.

```json
"required": true
```
