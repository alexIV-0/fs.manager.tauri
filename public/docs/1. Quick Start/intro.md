# fsManager

**fsManager** — настольное приложение для управления и обработки файлов и папок на основе Electron + React.

## Основные возможности

- Навигация по файловой системе с многоколоночным видом
- Нодовый редактор для описания процессов обработки
- Плагины — расширение функциональности через `.fsmplug` модули
- Пресеты настроек, документация по каждой ноде

## С чего начать

1. Откройте проект через диалог выбора папки
2. В графе нодов соберите нужный процесс
3. Нажмите кнопку запуска на верхней панели

Документация будет наполняться по мере развития приложения.
