# fsManager

**fsManager** — настольное приложение для управления и обработки файлов и папок на основе Tauri + React.

## Основные возможности

- Навигация по файловой системе с многоколоночным видом
- Нодовый редактор для описания процессов обработки
- Плагины — расширение функциональности через `.fsmplug` модули (ноды)
- Пресеты настроек, документация по каждой ноде

## Основной принцип

Поиск идет только по папкам IN внутри папки проекта, которая находится внутри главной папки.
т.е. путь для поиска такой:
mainFolder/projectFolder/IN

в этой папке каждый элемент обрабатывается по отдельности. т.е. можно закинуть 10 файлов и каждый из них будет обработан по отдельности.

Если нужно обработать несколько файлов одновременно - обрабатываем через папку. Папку создаем сами. Самое главное при работе с папками помнить что если процесс запущен, то папка может взяться в работу в любой момент, поэтому что бы она не бралась в работу нужно прописывать в само начале знак - (минус). Так программа будет знать что папка еще не готова для обработки. Как только она наполниться необходимыми файлами, нужно убрать знак "-" из имени папки.

## Основной принцип в выстраивании процесса нодами

Т.к. изначально мы не знаем ни имени файла, ни его характеристики, вся настройка идет через тип файла (видео, аудио, картинка и т.д.)
У каждой ножы есть только один выход и в нем будет один тип файла. Но это не означает что файл будет один.
У каждой ноды есть inputs. Каждый input работает только с одним конектером и только со своими типами файлов. т.е. если он принимает только видео, подключить туда аудио не получится.

Есть еще один нюанс в построении процесса обработки. Помимо соединений нод (это приоритер в построении цепочки обработки), на приоритетность нод влияет их положение на рабочем столе. т.е. те ноды, которые находятся левее будут обработаны первыми. Это важно только для проектов с moho персонажами. т.к. там нужна отдельно аудио дорожка, но дальше по флоу она не учавствует. (это просто особенность)

## С чего начать

1. Добавте главную папку
2. Добавте папку проекта
3. В графе нодов соберите нужный процесс
4. Нажмите кнопку запуска на верхней панели

Документация будет наполняться по мере развития приложения.
