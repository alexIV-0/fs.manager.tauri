# Подключение вашего YouTube-канала к автопубликации

> Этот гайд — для владельца канала. Пройдя его, вы разрешите программе **автоматически
> публиковать видео на ваш канал в открытом (public) доступе**. Настройка делается **один раз**.
> Займёт ~30 минут активных действий + ожидание проверки Google (обычно недели).

## Коротко: что и почему

Чтобы программа могла постить на **ваш** канал, вы создаёте **свой** проект в Google Cloud и
выдаёте программе доступ. Это сделано намеренно:

- **Канал и контент — ваши.** Вся ответственность за видео (авторские права, правила
  сообщества) остаётся на вашем канале и аккаунте.
- **Доступ — ваш.** Лимиты (квота) и разрешение на публикацию принадлежат вашему проекту, а не
  разработчику программы. Программа — лишь инструмент, который постит от вашего имени.

Важно понимать заранее: **пока Google не одобрит ваш проект (аудит), все загруженные через
программу видео будут приватными** (видны только вам). После одобрения — начнут публиковаться
открыто автоматически. Поэтому реальные публикации начинайте только **после** прохождения
проверки (шаг 5).

## Что понадобится

- Google-аккаунт, на котором находится ваш **YouTube-канал**.
- Страница с **политикой конфиденциальности** (Privacy Policy) в интернете — её попросят на
  проверке. Если нет — подойдёт простая страница на вашем сайте/блоге.

---

## Шаг 1. Создать проект Google Cloud

1. Откройте [console.cloud.google.com/projectcreate](https://console.cloud.google.com/projectcreate).
2. **Project name** — любое, напр. `my-youtube-autopost`.
3. Нажмите **Create** и дождитесь создания. Вверху страницы выберите созданный проект.

*Проект — это «рабочее пространство», внутри которого включается доступ к YouTube.*

## Шаг 2. Включить YouTube Data API v3

1. Откройте [страницу YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com)
   (убедитесь, что выбран ваш проект — вверху).
2. Нажмите **Enable** (Включить).

*Это включает саму возможность работать с YouTube из программы.*

## Шаг 3. Настроить экран согласия (OAuth consent screen)

1. Откройте [OAuth consent screen](https://console.cloud.google.com/apis/credentials/consent).
2. **User type: External** → Create.
3. Заполните обязательные поля:
   - **App name** — название (увидите вы при входе), напр. «Автопостинг [ваш канал]».
   - **User support email** — ваш email.
   - **App domain / Privacy policy link** — ссылка на вашу политику конфиденциальности.
   - **Developer contact information** — ваш email.
4. Сохраняйте по шагам (Save and Continue).
5. **Publishing status: переведите в `Production`** (кнопка «Publish app»).
   *Зачем: в режиме Testing доступ протухает каждые 7 дней. В Production — работает постоянно.*

> Меню Google иногда выглядит иначе (вкладки Branding / Audience / Clients в «Google Auth
> Platform») — смысл тот же: External, заполнить данные, опубликовать (Production).

## Шаг 4. Создать доступ для программы (OAuth client)

1. Откройте [Credentials](https://console.cloud.google.com/apis/credentials) → **Create
   Credentials → OAuth client ID**.
2. **Application type: Desktop app**.
3. Name — любое, напр. `autopost-desktop` → **Create**.
4. Появятся **Client ID** и **Client secret** — **скопируйте их** (или скачайте). Их вы
   передадите в программу на шаге 6.

*Это «ключи», которыми программа входит в ваш проект. Client secret храните как пароль.*

## Шаг 5. Пройти проверку Google (аудит) — обязательно для публичных видео

Это **главный шаг для открытой публикации**. Без него видео останутся приватными навсегда.

1. Откройте [форму аудита YouTube API](https://support.google.com/youtube/contact/yt_api_form).
2. Заполните заявку. Что попросят (подготовьте заранее):
   - Данные проекта (Project number/ID — виден в консоли).
   - Описание, **как вы используете API** (напр.: «автоматическая публикация собственных видео
     на свой канал через приложение-автопостер»).
   - **Ссылку на политику конфиденциальности.**
   - Обычно — **демонстрацию** (короткое видео/скринкаст), как проходит вход и загрузка.
   - Подтверждение соответствия [правилам для разработчиков YouTube API](https://developers.google.com/youtube/terms/developer-policies).
3. Отправьте и ждите ответа. **Сроки — недели**, Google может задать уточняющие вопросы или
   попросить доработать. Иногда с первого раза отклоняют — тогда исправляете и подаёте снова.

*Пока проверка не пройдена — программой можно пользоваться, но видео будут приватными (для
теста/подготовки). Реальные публичные публикации — после одобрения.*

## Шаг 6. Подключить канал в программе

1. В программе откройте ноду постинга YouTube → **«Добавить канал»**.
2. Вставьте **Client ID** и **Client secret** из шага 4.
3. Нажмите вход — откроется браузер с Google. Выберите свой аккаунт → **выберите нужный канал**
   (если у аккаунта их несколько) → разрешите доступ.
   - Если увидите «Google hasn't verified this app» до прохождения аудита — это ожидаемо, можно
     продолжить (Advanced → Proceed): это ваш собственный проект.
4. Готово — канал подключён. Программа будет публиковать на него по расписанию.

*Повторите шаг 6 для каждого канала, который хотите подключить (для каждого — свой вход).*

---

## Что важно понимать

- **До аудита — только приватные видео.** Причём приватные «залоченные»: их нельзя сделать
  публичными вручную и нельзя вернуть — только перезалить после одобрения. Поэтому не гоняйте
  реальный контент до шага 5.
- **После аудита — публикуется открыто автоматически.** В программе ничего менять не нужно.
- **Ответственность за контент — на вас** (канал ваш). Жалобы/страйки касаются вашего канала.
- **Лимит публикаций** — ваш проект даёт ~100 загрузок в сутки (стандартная квота). Обычно с
  запасом; если нужно больше — в той же форме аудита можно запросить расширение.

## Частые вопросы

- **Обязательно ли платить?** Нет, YouTube Data API и Google Cloud проект для этого бесплатны.
- **Можно ли без аудита?** Только если согласны, что видео будут приватными. Для открытой
  публикации аудит обязателен.
- **Что если сменю пароль Google / отзову доступ?** Доступ слетит — нужно будет заново пройти
  шаг 6. Отозвать доступ можно на [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
- **Несколько каналов на одном аккаунте?** Подключайте каждый отдельно (шаг 6), выбирая нужный
  канал при входе.
