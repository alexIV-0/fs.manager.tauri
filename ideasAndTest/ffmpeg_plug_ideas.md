# ffmpeg — справочник фильтров (идеи для плагинов)

Заметка-памятка: что из ~400 фильтров ffmpeg стоит иметь в виду для будущих плагинов.
Сначала «костяк» по частоте использования, потом подробно темы: стабилизация, дефликер,
деинтерлейс, текст/титры, чистка. Команды реальные.

> Привязка к проекту: список используемых возможностей живёт в `src-tauri/ffmpeg_requirements.json`
> (gate после скачивания сборки). Спец-фильтры ниже (vidstab, arnndn, rubberband) требуют
> особых флагов сборки и/или файлов моделей — если возьмём в работу, добавить в `optional`/`required`.

## Видео-фильтры

### Тир 1 — рабочая лошадка (используешь почти всегда)

| Фильтр | Что делает |
|---|---|
| `scale` | масштабирование. `scale=1920:-2` (−2 = авто с чётностью) |
| `crop` / `pad` | обрезка / добавление полей. `crop=w:h:x:y`, `pad` для леттербокса |
| `fps` / `framerate` | смена частоты кадров (дроп/дубль vs интерполяция) |
| `setpts` / `asetpts` | управление таймингом (скорость, `setpts=0.5*PTS` = 2× быстрее) |
| `overlay` | наложение одного видео/картинки на другое (x, y, enable) |
| `format` | смена пиксель-формата (`format=yuv420p` перед энкодом) |
| `fade` / `xfade` | затухания / переходы между клипами |
| `transpose`, `hflip`, `vflip`, `rotate` | повороты/отражения |
| `concat` | склейка (как фильтр или демуксер — у нас демуксер в `join.ts`) |
| `drawtext` | текст поверх видео (подробно ниже) |

### Тир 2 — частые, цвет и композ

| Фильтр | Что делает |
|---|---|
| `eq` | базовый цвет: brightness/contrast/saturation/gamma (есть) |
| `curves` | кривые по RGB-каналам (как в фотошопе), пресеты |
| `colorbalance` | баланс теней/средних/светов |
| `colorchannelmixer` | микс каналов (ч/б, sepia, swap RGB) |
| `lut3d` / `lut1d` | применение LUT-файла (.cube) — кинолуки |
| `hue` | оттенок/насыщенность, анимируемый |
| `colorspace` / `zscale` | корректные преобразования цв. пространств (rec709↔rec2020, tonemap HDR→SDR) |
| `blend` | смешивание двух потоков по blend-режимам (multiply, screen…) |
| `unsharp` | резкость (unsharp mask); `cas` — современная контраст-адаптивная резкость |
| `gblur`, `boxblur`, `avgblur` | размытия (gaussian/box; `boxblur` есть) |
| `vignette` | виньетка |
| `zoompan` | эффект Кена Бёрнса (зум/пан по статике) |
| `hstack` / `vstack` / `xstack` | сетка/сплит-скрин из нескольких источников |
| `tile` | контактный лист (раскадровка в один кадр) |

### Тир 3 — реже, специальные / аналитические

- `minterpolate` — motion-интерполяция (slow-mo / смена fps), тяжёлый
- `tblend` / `tmix` / `tmedian` — временное смешивание
- `geq` — попиксельные формулы (есть)
- `lenscorrection` / `v360` — дисторсия, 360°
- `perspective` / `remap` — геом. коррекция
- `edgedetect` / `sobel` / `convolution` — края / свёртки
- `chromakey` / `colorkey` / `lumakey` / `despill` — кеинг (наш профиль)
- `histogram` / `waveform` / `vectorscope` / `signalstats` — видеоскопы и анализ
- `cropdetect` — авто-детект чёрных полей
- `blackdetect` / `freezedetect` / `blackframe` — поиск проблемных сегментов
- `ssim` / `psnr` — метрики качества

## Подробно по темам

### 🎯 Стабилизация — `vidstab` (двухпроходный)

Лучшая в ffmpeg, но требует сборки с `--enable-libvidstab`.
Проверка: `ffmpeg -filters | grep vidstab` (в `ffmpeg_requirements.json` его нет — BtbN gpl содержит, martin-riedl надо проверить).

```bash
# Проход 1 — анализ, пишет вектора движения в файл
ffmpeg -i in.mp4 -vf vidstabdetect=shakiness=5:accuracy=15 -f null -

# Проход 2 — применение + лёгкая резкость (стаб слегка мылит)
ffmpeg -i in.mp4 -vf "vidstabtransform=smoothing=30:zoom=0,unsharp=5:5:0.8" out.mp4
```

- `smoothing` — окно сглаживания (больше = плавнее, но «уплывает»)
- `zoom` — компенсация краёв обрезкой
- `deshake` — однопроходный, проще, но заметно хуже (для быстрой прикидки)

### 🎯 Дефликер — `deflicker`

Убирает мерцание яркости (старая плёнка, рассинхрон с лампами/затвором, таймлапс):

```bash
ffmpeg -i in.mp4 -vf "deflicker=size=5:mode=pm" out.mp4
```

- `size` — окно усреднения в кадрах
- `mode` — арифм./геом./медианное среднее
- Для **бандинга** в градиентах — другое: `deband` или `gradfun`

### 🎯 Деинтерлейс (чересстрочное → прогрессив)

| Фильтр | Когда |
|---|---|
| `yadif` | дефолт, быстрый, 95% случаев. `yadif=mode=1` (удвоение fps) |
| `bwdif` | **лучше yadif** — motion-adaptive, тот же синтаксис. Рекомендую по умолчанию |
| `nnedi` | максимум качества (нейросеть), медленный, нужен файл весов |
| `w3fdif`, `estdif`, `kerndeint` | альтернативы под спец-материал |

```bash
ffmpeg -i interlaced.mp4 -vf "bwdif=mode=send_frame" out.mp4
```

Отдельно: **обратный телесин** (24→30 fps плёнка с pulldown) — `fieldmatch,decimate` или `pullup`. Это не то же, что деинтерлейс.

### 🎯 Текст и титры

`drawtext` — для динамики/таймкода/счётчиков:

```bash
ffmpeg -i in.mp4 -vf "drawtext=fontfile=/path/font.ttf:text='Привет':\
fontsize=48:fontcolor=white:x=(w-text_w)/2:y=h-80:\
box=1:boxcolor=black@0.5:boxborderw=10:\
enable='between(t,2,6)'" out.mp4
```

Умеет: `textfile=` (текст из файла), `%{pts\:hms}` (таймкод), `shadowx/y`, `borderw/bordercolor`, анимация координат по `t`, `enable` (таймлайн появления).

`subtitles` — прожечь субтитры (через libass, поддерживает стили):

```bash
ffmpeg -i in.mp4 -vf "subtitles=subs.srt:force_style='FontSize=24'" out.mp4
```

`ass` — рендер ASS/SSA со сложной типографикой/анимацией (используется в `addTitle.ts`). Для красивых титров ASS мощнее, чем drawtext.

### 🎯 Чистка видео / убирание артефактов

Связка фильтров, подбирают по типу шума.

**Шумоподавление (denoise):**

| Фильтр | +/− |
|---|---|
| `hqdn3d` | быстрый, простр.+временной, дефолт для лёгкой чистки. `hqdn3d=4:3:6:4` |
| `nlmeans` | non-local means, качественно, **медленно** |
| `bm3d` | топ-качество, **очень медленно** |
| `atadenoise` | временной, хорош для статичной камеры |
| `fftdnoiz` | FFT-3D, баланс качество/скорость |
| `vaguedenoiser` | вейвлет, мягкий |
| `removegrain` | лёгкий пространственный, дёшево |

**Артефакты сжатия:**

- `deblock` — убирает блочность (макроблоки H.264/JPEG)
- `pp7` / `spp` / `uspp` — постпроцессинг (деблок + деринг), от лёгкого к тяжёлому
- `deband` / `gradfun` — устранение полос в градиентах (небо)
- `chromanr` — шум в цветовых каналах

**Типовой клин-ап пайплайн** (порядок важен — чистим до резкости):

```bash
ffmpeg -i dirty.mp4 -vf "\
  bwdif,\                # деинтерлейс (если нужен)
  hqdn3d=3:2:4:3,\       # шум
  deblock,\              # артефакты сжатия
  deband,\               # бандинг
  cas=0.4,\              # лёгкая резкость в конце
  format=yuv420p" clean.mp4
```

**Совет по порядку:** деинтерлейс → денойз → деблок/дебанд → (цветокор/eq) → резкость → format.
Резкость и масштаб всегда в конце, чтобы не усиливать шум.

## Аудио-фильтры

### Тир 1 — частые

| Фильтр | Что делает |
|---|---|
| `volume` | усиление/ослабление (`volume=1.5` или `volume=-3dB`) |
| `loudnorm` | нормализация по EBU R128 (стандарт для вещания/YouTube) |
| `dynaudnorm` | динамическая нормализация (выравнивание громкости по ходу) |
| `atempo` | смена темпа без питча (есть; цепочкой для >2×) |
| `amix` / `amerge` | микс / объединение дорожек (`amix` есть) |
| `apad` / `adelay` / `atrim` | паддинг/сдвиг/обрезка (`apad` есть) |
| `aresample` | ресемплинг частоты дискретизации |
| `highpass` / `lowpass` | срез низов/верхов (`highpass=f=80` убрать гул) |
| `pan` | ремаппинг каналов (стерео→моно, downmix) |

### Тир 2 — обработка/динамика

| Фильтр | Что делает |
|---|---|
| `acompressor` | компрессор динамики |
| `alimiter` | лимитер (потолок громкости без клиппинга) |
| `agate` | гейт (отсечь тихий фон/шум между фразами) |
| `equalizer` / `anequalizer` / `firequalizer` | параметрический/граф. эквалайзер |
| `bass` / `treble` | shelf-коррекция низов/верхов |
| `speechnorm` | выравнивание громкости речи |

### 🎯 Чистка голоса/аудио (denoise)

| Фильтр | +/− |
|---|---|
| `arnndn` | RNN-нейросеть, лучшее для голоса/шумного фона, нужен файл модели (.rnnn) |
| `afftdn` | FFT-денойз, встроенный, хорош для постоянного шума (гул/шипение). `afftdn=nf=-25` |
| `anlmdn` | non-local means для аудио, мягкий |

**Типовой клин-ап голоса:**

```bash
ffmpeg -i voice.wav -af "\
  highpass=f=80,\        # убрать НЧ-гул/рокот
  afftdn=nf=-25,\        # шумодав (фон/шипение)
  acompressor=ratio=3,\  # выровнять динамику
  loudnorm=I=-16:TP=-1.5" clean.wav   # нормализация
```

### Тир 3 — эффекты/анализ

`aecho` (эхо), `aphaser` / `achorus` / `flanger` / `tremolo` / `vibrato` (модуляция),
`acrusher` (бит-краш), `rubberband` (питч+темп независимо, нужен `--enable-librubberband`),
`silenceremove` / `silencedetect` (резка тишины), `astats` / `ebur128` / `volumedetect` (анализ громкости/пиков).

## Практическая привязка к проекту

1. **Стабилизация и `arnndn`/`rubberband`** требуют спец флагов сборки (`libvidstab`, `librubberband`)
   и файлов моделей. Если возьмём — добавить `vidstab`/`librubberband` в `optional` (или `required`)
   `ffmpeg_requirements.json`, чтобы gate проверял наличие. Сейчас их там нет.
2. **`drawtext`/`subtitles`** опираются на libass + наличие шрифтов — `ass` уже в `required`,
   так что текст-стек покрыт.
3. **«Живое превью» этих фильтров**: интерактив параметров лучше на WebGL-шейдерах,
   а ffmpeg — для финального прохода и стоп-кадров (это и реализует движок `preview_render_frame` +
   `usePreviewCache`). Временные фильтры (vidstab/deflicker/denoise/deinterlace) — только ffmpeg-ярус.
